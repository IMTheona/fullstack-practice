# fullstack-practice
全栈暑期实战-SpringBoot+Vue3
## 开发环境(2026.7.4)
-Java
-Node.js
-JDK
-MySQL
-Redis
-pinia
## 主项目-黑马程序员“大事件”（分支big-event+vue）
-技术栈：Springboot、Mybatis、redis(登录优化）、JWT（登录验证）、validation
-主要模块：用户模块、文章类型模块、文章模块
-前后端分离
## 完成功能：
-用户注册
-用户登录（后端Redis存储令牌,前端pinia存储）
-用户信息更改
-文章分类
-文章管理
-文件上传（阿里云）
